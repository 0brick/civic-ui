# EN 301 549

- **Standard:** EN 301 549, Accessibility requirements for ICT products and services (ETSI / CEN / CENELEC)
- **Versions:**
  - **V3.2.1 (2021-03):** cited in the Official Journal of the EU and the legal reference under the Web Accessibility Directive (EU) 2016/2102 and the European Accessibility Act (EU) 2019/882. Clause 9 requires WCAG 2.1 Level A and AA, including 4.1.1 Parsing.
  - **V4.1.1 (published September 2026):** clauses 9 to 11 based on WCAG 2.2 Level AA, 4.1.1 Parsing removed, new user preference requirements. Becomes the legal reference once cited in the Official Journal.
- **Source:** <https://www.etsi.org/standards> (search for EN 301 549)
- **Target:** both versions. In practice: WCAG 2.2 AA plus 4.1.1, see [wcag-2.2.md](wcag-2.2.md).
- **Last reviewed:** 2026-10-21. Recheck the Official Journal citation status of V4.1.1 at every review.

## Relevant clauses

| Clause | Requirement | Scope | How Civic UI meets it |
| --- | --- | --- | --- |
| 5.2 | Activation of accessibility features | Library | No feature that has to be switched on; accessible by default |
| 5.3 | Biometrics | Site | Not used by the library |
| 7.1, 7.2, 7.3 | Captions, audio description and their controls in media players | Site | The library ships no media player. `HeroSection` background video is muted and decorative; players loaded through `ConsentEmbed` are the provider's |
| 9 (all) | Web content: WCAG success criteria, Level A and AA | Library / Shared / Site | Per criterion in [wcag-2.2.md](wcag-2.2.md) |
| 9.4.1.1 (V3.2.1) | Parsing | Library | Unique ids via `useId()`, no nested interactive elements, no dangling ARIA references. axe and unit tests |
| 9 (V4.1.1) | Do not override user agent modes that present content according to the user's accessibility settings | Library | Supports `forced-colors` (`test/styles/forced-colors.spec.js`), `prefers-reduced-motion` (`test/styles/motion-and-focus.spec.js`) and the system color scheme (`useColorMode` in `auto` mode) |
| 11.7 | User preferences: follow platform settings for color, contrast, font size | Library | Same as above; type scale in `rem`, so browser font size settings apply |
| 12.1.1, 12.1.2 | Product documentation lists accessibility features and is itself accessible | Library | [docs/accessibility.md](../docs/accessibility.md); the playground documentation passes the e2e axe run |
| 12.2 | Support services communicate accessibility information | Library | Issues on GitHub, [SECURITY.md](../SECURITY.md) contact |

Clauses for hardware, real-time communication, closed functionality and non-web software do not apply to a web component library.

## Verification

Covered by the WCAG verification (`npm test`, `npm run test:a11y-e2e`). V4.1.1 adds no web requirement that is not already tested.
